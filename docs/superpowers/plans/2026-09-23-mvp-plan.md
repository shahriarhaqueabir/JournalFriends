**Goal:** Ship a lean, verified MVP — Journal · Tasks · Mood · Settings + AI chat — with a Companion persona, dual-source mood tracker, and in-chat extraction approval, on the existing Tauri v2 + llama.cpp codebase.

**Architecture:** No schema/surface deletion. **Tech Stack:** Tauri v2 / Rust (cargo 1.95), rusqlite bundled-sqlcipher, vanilla JS ESM (no bundler), Chart.js 4.5.1 vendored, SortableJS (not needed for mood). Verified runtime: bundled `llama-server.exe` + GGUFs in `%APPDATA%/ArnoldJournals/engines|models`, live `arnold.db`.

## Global Constraints

- Migration SQL files must contain **no** `BEGIN`/`COMMIT` — the runner wraps each migration in a `rusqlite` transaction and rejects explicit transactions (`db/migrations.rs::ensure_no_explicit_transactions`), D-97.
- Every DB access goes through `state.db()?` + `db::pool::with_conn` (read) / `with_tx` (write), D-33.
- Every command returns `Result<T, AppError>`; new commands are private `async fn` in lib.rs (F-011 — no `pub` in crate root).
- No new dependencies (D-42). All user/model content rendered via `escapeHtml` from `src/js/sanitize.js` (escape-first).
- AI never writes to the DB without user confirmation (D-19); all confirmation flows keep the 300s timeout behaviour.
- Dates stored ISO-8601 UTC; **day keys are local `YYYY-MM-DD`** (D-133) — never `toISOString().slice(0,10)`.
- `cargo check` must finish 0 errors; `cargo fmt --check` clean; `node --check <file>` clean on every touched `.js`; `cargo test` green (rebuilt suite).
- Commit each task separately with a conventional message. `docs/superpowers/*`, `.memory` are gitignored (F-003) — only source commits here.
- Context budget: default `llama_ctx_size` 16384 (D-93); the composed chat prompt must stay well under it.

Baseline: head `6c6693c`. Working tree holds an **adopted-but-uncommitted** `loadView` caching change in `src/js/app.js` (uses `dataset.viewLoaded`). Task 1 commits it. All later tasks assume that change is present.

    pub mood: String,
    pub source: String,
    #[serde(default)]
    pub note: Option<String>,

pub fn merge_days(manual: Vec<MoodDay>, inferred: Vec<MoodDay>) -> Vec<MoodDay> {
    let mut by_date: std::collections::HashMap<String, MoodDay> = std::collections::HashMap::new();
    for d in manual {
        by_date.insert(d.date.clone(), d);
    }
    for d in inferred {
        if !by_date.contains_key(&d.date) {
            by_date.insert(d.date.clone(), d);
        }
    }
    let mut days: Vec<MoodDay> = by_date.into_values().collect();
    days.sort_by(|a, b| a.date.cmp(&b.date));
    days
}

pub fn checkin(conn: &Connection, id: &str, mood: &str, note: &str, date: &str, now: &str) -> Result<(), AppError> {
    conn.execute(
        "INSERT INTO mood_checkins (id, mood, note, checkin_date, created_at)
         VALUES (?1, ?2, ?3, ?4, ?5)
         ON CONFLICT(checkin_date) DO UPDATE SET
           mood = excluded.mood,
           note = excluded.note,
           created_at = excluded.created_at",
        params![id, mood, note, date, now],
    )?;
    Ok(())
}

pub fn manual_days(conn: &Connection, start: &str, end: &str) -> Result<Vec<MoodDay>, AppError> {
    let mut stmt = conn.prepare(
        "SELECT checkin_date, mood, note FROM mood_checkins
         WHERE checkin_date >= ?1 AND checkin_date <= ?2
         ORDER BY checkin_date ASC",
    )?;
    let rows = stmt.query_map(params![start, end], |row| {
        Ok(MoodDay { date: row.get(0)?, mood: row.get(1)?, source: "manual".into(), note: row.get(2)? })
    })?;
    let mut out = Vec::new();
    for r in rows {
        out.push(r?);
    }
    Ok(out)
}

pub fn inferred_days(conn: &Connection, start: &str, end: &str) -> Result<Vec<MoodDay>, AppError> {
    let mut stmt = conn.prepare(
        "SELECT date, mood FROM (
           SELECT date(created_at) AS date,
                  json_each.value AS mood,
                  COUNT(*) AS c,
                  ROW_NUMBER() OVER (PARTITION BY date(created_at) ORDER BY COUNT(*) DESC) AS rn
           FROM journal_entries, json_each(emotions)
           WHERE is_deleted = 0 AND date(created_at) >= ?1 AND date(created_at) <= ?2
           GROUP BY date, mood
         ) WHERE rn = 1
         ORDER BY date ASC",
    )?;
    let rows = stmt.query_map(params![start, end], |row| {
        Ok(MoodDay { date: row.get(0)?, mood: row.get(1)?, source: "ai".into(), note: None })
    })?;
    let mut out = Vec::new();
    for r in rows {
        out.push(r?);
    }
    Ok(out)
}

pub fn delete(conn: &Connection, date: &str) -> Result<(), AppError> {
    conn.execute("DELETE FROM mood_checkins WHERE checkin_date = ?1", params![date])?;
    Ok(())
}
```

#[tauri::command]
async fn mood_checkin(
    state: tauri::State<'_, AppState>,
    mood: String,
    date: String,
    note: Option<String>,
) -> Result<(), AppError> {
    if !crate::db::mood::validate_mood(&mood) {
        return Err(AppError::InvalidInput(format!("Unknown mood: {mood}")));
    }
    if chrono::NaiveDate::parse_from_str(&date, "%Y-%m-%d").is_err() {
        return Err(AppError::InvalidInput(format!("Invalid date: {date}")));
    }
    let db = state.db()?;
    let id = Uuid::new_v4().to_string();
    let note_owned = note.unwrap_or_default();
    db::pool::with_tx(db, move |tx| {
        crate::db::mood::checkin(tx, &id, &mood, &note_owned, &date, &Utc::now().to_rfc3339())
    })
    .await
}

#[tauri::command]
async fn mood_list(
    state: tauri::State<'_, AppState>,
    start: String,
    end: String,
) -> Result<Vec<crate::db::mood::MoodDay>, AppError> {
    let db = state.db()?;
    db::pool::with_conn(db, move |conn| {
        let manual = crate::db::mood::manual_days(conn, &start, &end)?;
        let inferred = crate::db::mood::inferred_days(conn, &start, &end)?;
        Ok(crate::db::mood::merge_days(manual, inferred))
    })
    .await
}

#[tauri::command]
async fn mood_delete(
    state: tauri::State<'_, AppState>,
    date: String,
) -> Result<(), AppError> {
    let db = state.db()?;
    db::pool::with_tx(db, move |tx| crate::db::mood::delete(tx, &date)).await
}
```
